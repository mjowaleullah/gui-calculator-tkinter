# 🧮 Tkinter Calculator

A simple desktop calculator application built with Python's Tkinter library.

## 📸 Preview

A clean, minimal GUI calculator with basic arithmetic operations.

## 🚀 Features

- Addition, Subtraction, Multiplication, Division
- Clear button to reset input
- Lightweight and fast — no external libraries needed

## 🛠️ Requirements

- Python 3.x
- Tkinter (comes pre-installed with Python)

## ▶️ How to Run

```bash
#5 python calculator.py
```

## 📁 Project Structure

```
tkinter-calculator/
│
└── #5 calculator.py       # Main application file
```
